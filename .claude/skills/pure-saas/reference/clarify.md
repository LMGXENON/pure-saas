# Clarify: UX Microcopy, Error Recovery & Active Voice

Use `/pure-saas clarify [target]` to eliminate confusing jargon, passive copy, vague buttons, and unhelpful error messages.

---

## 1. UX Copy Principles

1. **Active Verb Buttons:**
   - Controls must name the exact action they take:
     - ✗ "Submit" / "Click here" / "Proceed"
     - ✓ "Deploy to Production" / "Create Project" / "Save Changes"
2. **Helpful Error Messages:**
   - An error message must state what happened, why, and how to recover:
     - ✗ "An unexpected error occurred."
     - ✓ "Could not connect to the database. Check your connection string and click Retry."
3. **Domain-Authentic Terminology:**
   - Speak in the natural vocabulary of the user's domain (e.g., in a cloud console: "Cluster", "Region", "Ingress", "Replica"). Never use generic consumer placeholders.
4. **Transparent Pricing Terms:**
   - Explain what happens after a trial ends, what is included in each tier, and whether cancellation is instant.
