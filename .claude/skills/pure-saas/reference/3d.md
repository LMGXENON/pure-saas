# Procedural Three.js Models & img2threejs Pipeline

Pure SaaS supports code-only, procedural Three.js component synthesis in TypeScript with zero binary asset dependencies (`.gltf`, `.glb`).

---

## 1. Why Procedural Three.js?

- **Zero Asset Bloat:** 100% written in TypeScript using Three.js geometric primitives (`BoxGeometry`, `CylinderGeometry`, `ExtrudeGeometry`).
- **Instantly Renderable:** Zero asset download delay; models instantiate in sub-millisecond execution.
- **Parametric & Interactive:** Dynamic properties (color tokens, scale, geometry counts) bind directly to UI state and design tokens.
- **Production-Ready Hooks:** Emits standard `THREE.Group` objects with built-in `userData.tick(delta, elapsed)` animation methods and memory cleanup routines.

## 3. The 6-Pass Sculpting Pipeline

When reconstructing 3D models from reference images:
```
[2D Reference Image] ──► [Pass 1: Blockout] ──► [Pass 2: Structural] ──► [Pass 3: Form Details]
                     ──► [Pass 4: Materials] ──► [Pass 5: Lighting/Rig] ──► [Pass 6: Optimization]
```

1. **Pass 1: Blockout:** Bounding hierarchy & volumetric mass.
2. **Pass 2: Structural:** Joints, bevels, cavities, and cuts.
3. **Pass 3: Form Details:** Buttons, ports, vents, indicators.
4. **Pass 4: Materials & PBR:** Metalness, roughness, emissive accents.
5. **Pass 5: Lighting & Rig:** Shadows, pivot points, interaction hooks.
6. **Pass 6: Optimization:** Geometry disposal, render loop, tick hook.

---

## 4. Component Architecture & Memory Lifecycle

Every procedural 3D model conforms to the strict `ProceduralModel` contract:
```typescript
export interface ProceduralModel extends THREE.Group {
  userData: {
    tick: (delta: number, elapsed: number) => void;
    dispose: () => void;
  };
}
```

### Lifecycle Rules
- Geometry and materials are tracked in disposal arrays.
- On React component unmount (`useEffect` cleanup), call `model.userData.dispose()` and `renderer.dispose()`.
- Maximum polygon count: Under 5,000 triangles to guarantee 60fps on mobile devices.
