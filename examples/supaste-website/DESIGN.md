# DESIGN.md — Supaste Website Recreation

## 1. Reference Overview
- **Product:** Supaste
- **Platform:** Marketing website for native macOS application
- **Reference URL:** https://www.supaste.com/
- **Primary Objective:** Recreate the website's visual identity, section hierarchy, typography, product presentation and interactions as faithfully as possible.
- **Core Value Proposition:** Local-first clipboard and screenshot history application for macOS. Copy once, reuse anytime across text, links, images, files, code, colors, and screenshots in a beautiful searchable timeline.

### Core Design Principles
- Minimal, editorial, product-led presentation.
- Large expressive typography with high-contrast messaging (`Inter Display` paired with italic `Instrument Serif`).
- Native macOS aesthetic: rounded windows, subtle inner borders, translucent notch preview, and system-like controls.
- Generous whitespace and intentional section rhythm.
- Purposeful spring motion and optical depth without generic SaaS gradient slop.
- Clear, unambiguous download and purchasing actions throughout.

---

## 2. Design Direction
- **Style Archetype:** Minimal Editorial with macOS Native Polish.
- **Visual Mood:** Crisp, airy, high-utility, understated luxury. Light canvas `#FFFFFF` and surface `#F7F7F7` grounded by deep `#000000` text and accents.
- **Depth & Surfaces:** Multi-layered elevation using fine border lines (`rgba(0, 0, 0, 0.08)` and `#E5E5E5`), delicate box-shadows (`0 10px 30px rgba(0, 0, 0, 0.04)`), and rounded corners (20px to 40px cards).
- **Anti-Slop Safeguards:** No generic purple/cyan gradient text, no floating 3D neon shapes, no emoji icons used for UI controls, and no low-contrast gray text.

---

- **Max Container Width:** 1200px centered with fluid gutter padding (`clamp(16px, 4vw, 40px)`).
- **Content Measure:** Longform reading paragraphs constrained to `65ch` max width.
- **Card Grids:**
  - Feature 2-column asymmetric compositions (55% visual, 45% text).
  - 3-column responsive card grids switching to 2-column at 840px and 1-column at 640px.

- **Code & Metadata Mono:** `'Fragment Mono', 'SF Mono', Menlo, monospace`, weight 400, for keyboard shortcuts, hex values, and syntax chips.

3. **Notch Shelf Simulator:** Dynamic MacBook Pro notch simulation with interactive pull-down drawer showcasing live clips.
4. **Interactive OCR Scanner:** Screenshot preview card with selectable text overlay and OCR copy button.

7. **Clip Cards:** Reusable preview tiles for text snippets, hex colors (`#0071E3`), screenshots, code blocks, and SVG icons.
8. **Toast Notification:** Floating Apple-grade pill notification ("Copied to clipboard") when user interacts with preview cards.

## 10. Motion and Interaction
- **Entrance Transitions:** Subtle vertical stagger entrance (`transform: translateY(20px)` to `0`, `opacity: 0` to `1`) using `cubic-bezier(0.2, 0.8, 0.2, 1)`.
- **Interactive Notch Drawer:** Hovering or tapping the top notch expands a fluid shelf with bounce easing.
- **Hover Micro-Interactions:** Cards elevate slightly (`transform: translateY(-2px)`) with subtle shadow bloom (`0 12px 24px rgba(0,0,0,0.06)`).
- **Reduced Motion Support:** Respects `@media (prefers-reduced-motion: reduce)` by disabling transforms and transitions.

---

## 11. Responsive Behaviour
- **Desktop (1200px+):** Full 1200px container, multi-column feature layouts, interactive notch shelf, and side-by-side FAQ cards.
- **Tablet (768px – 1023px):** Header adapts with compact navigation, hero window scales fluidly, and feature tiles stack in a clean 2-column grid.
- **Mobile (375px – 767px):** Single-column vertical flow, full-width touch targets (minimum 44px), horizontally scrollable category tabs, and tap-to-expand FAQ accordions.
