# Design Brief: Operon Autonomous Engineering Control Plane

## Product Purpose
Operon is an engineering control plane designed for teams using autonomous AI coding agents (Claude Code, Cursor, Codex). Instead of granting uncontrolled access or loading thousands of tool schemas into context, Operon establishes a single authenticated gateway with an immutable System Contract, sandboxed test execution, and an explicit cryptographic release approval gate before changes touch production environments.

## Target Audience
- **DevOps & Platform Engineers:** Seeking to govern agent execution and protect live clusters.
- **Engineering Leads:** Needing visibility, contract compliance, and audit trails for agent-generated code.
- **AI-Native Developers:** Wanting seamless tool discovery without prompt-context schema saturation.

## Reference Analysis (Convio.dev)
- **Strengths Observed:** Editorial technical prose, layered dark canvas with subtle starfield/noise texture, high-density interactive mockups with status badges, 4-step segmented architectural walkthrough, and calm motion pacing.
- **Pure SaaS Adaptation:** Create original brand identity (Operon), original interface previews (release approval modal, gateway telemetry, schema contract diff), and native zero-dependency CSS/JS interactions.

## Approved Design Decisions
- Canvas: `#0a0a0b` deep carbon black with elevated `#121316` card surfaces.
- Text: `#ffffff` primary headings, `rgba(255, 255, 255, 0.75)` secondary prose, `rgba(255, 255, 255, 0.45)` muted labels.
- Borders: `rgba(255, 255, 255, 0.08)` hairline borders with `rgba(255, 255, 255, 0.2)` hover/focus transitions.
- Radii: `6px` for controls, `12px` for interface cards, `9999px` for pills.
- Easing: `cubic-bezier(.16, 1, .3, 1)` for reveals; instant jump when `prefers-reduced-motion` is active.
