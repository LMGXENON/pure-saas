# Visual Drift Comparison & 11-Item Quality Gates

Before claiming that a recreation is complete, perform rigorous side-by-side visual comparison against the original reference across an 11-item completion gate.

---

## 1. Core Dimensions & Methodology

| Dimension | Technical Detail |
| :--- | :--- |
| **Side-by-Side Viewport Audit** | Render reference and recreation at identical 1440px, 768px, and 375px widths |
| **Visual Difference Threshold** | Verify layout geometry, typography weights, and alignment match within strict tolerances |
| **Honest Verification Reporting** | Explicitly record verified, failed, and untested elements |

---

## 2. Implementation & Extraction Reference

```javascript
// 11-Item Pure SaaS Completion Checklist
1. Semantic Tokens Enforced (Zero raw hex codes).
2. Typography Scales & Tracking Verified.
3. 8pt Spatial Grid Aligned.
4. 8-State Component Matrix Complete.
5. Light & Dark Mode Contrast Verified (>= 4.5:1).
6. Hairline Borders & Materials Styled.
7. Fluid Physics Motion Integrated.
8. Reduced Motion Honored.
9. Responsive Breakpoints Tested (375px, 768px, 1440px).
10. Backend APIs & Data Contracts Preserved.
11. Anti-Slop Audit Passed (No generic AI slop).
```

---

## 3. Best Practices (Do's & Don'ts)

| Do | Don't |
| :--- | :--- |
| Perform honest side-by-side screenshot comparisons. | Never declare a recreation complete without testing at mobile and desktop viewports. |

## 4. Accessibility & Verification

- **Verify full keyboard tab navigation through the entire recreated interface.**

---

## 5. Anti-Slop Enforcement

- Never guess or approximate when live DOM styles or computed CSS variables can be directly verified.
