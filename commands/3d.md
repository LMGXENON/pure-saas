# Pure SaaS: /pure-saas 3d

Synthesize procedural, code-only Three.js 3D models written in TypeScript from 2D reference images or generate interactive 3D component scaffolds.

## Usage

```bash
/pure-saas 3d [image-path or scaffold-name]
# or
/pure-saas:3d [request]
```

**Target Scope:** `$ARGUMENTS`

---

## Operational Instructions

1. **Verify Prerequisites:**
   Run the prerequisites check to confirm environment readiness (Three.js, TypeScript, Canvas/WebGL support):
   ```bash
   npx pure-saas 3d check
   ```

2. **Evaluate Image Suitability:**
   Before attempting reconstruction, evaluate the input image against the suitability contract ([`references/img2threejs-pipeline.md`](../references/img2threejs-pipeline.md)):
   - Hard-surface objects with clear silhouettes and even studio lighting.
   - Reject blurred, cropped, or ambiguous images.

3. **Generate ObjectSculptSpec:**
   Extract dimensional bounds, color accents, and geometric features:
   ```bash
   npx pure-saas 3d spec <image-path> --out ./spec.json
   ```

4. **Execute 6-Pass Staged Sculpting:**
   - **Pass 1 (Blockout):** Root bounding volume and primary masses (`BoxGeometry`, `CylinderGeometry`).
   - **Pass 2 (Structural):** Functional subdivisions, joints, bevels, and pivot points.
   - **Pass 3 (Form Details):** Secondary details (ports, buttons, vents, dials).
   - **Pass 4 (Materials):** PBR standard materials, roughness, metalness, and emissive highlights.
   - **Pass 5 (Lighting & Rig):** Shadow casting and bounding collision volume.
   - **Pass 6 (Optimization):** Memory disposal hooks and `userData.tick` animation loop.

5. **Scaffold or Integrate Component:**
   ```bash
   npx pure-saas 3d scaffold <ModelName> --out ./src/components/<ModelName>3D.tsx
   ```

Consult [`references/components/procedural-threejs-models.md`](../references/components/procedural-threejs-models.md) for complete React / Three.js canvas integration code.
