# Pure SaaS Impact Comparison Demo Website

A standalone, production-grade comparison web application that demonstrates the observable difference between an unguided AI coding assistant and the **Pure SaaS** spatial design system.

---

## 1. Features & Viewing Modes

- **Side-by-Side Synchronized View:** Desktop dual-column layout comparing the Baseline (Without Pure SaaS) against the Treatment (With Pure SaaS).
- **Interactive Diff / Wipe Slider:** Drag a vertical divider across the canvas to inspect precise optical alignment and typographic rhythm differences in real time.
- **Dedicated Single-View Modes:** Full-canvas exploration of either implementation.
- **8-Dimension Audit Scorecard:** Side-by-side breakdown of the spatial geometry, gutter line alignment, optical icon lockup, proximity mathematics, and anti-slop rules.
- **Viewport Simulation:** Live toggle between Desktop (1440px), Tablet (768px), and Mobile (375px bounded frame).
- **Theme & Motion Controls:** Instant Light/Dark mode switcher with persistent theme tokens, plus a Reduced Motion mode toggle for accessibility.

---

## 2. Running Locally

```bash
# Navigate to demo-comparison directory
cd demo-comparison

# Install dependencies
npm install

# Start development server on port 3001
npm run dev

# Or build for production
npm run build
```

Alternatively, from the repository root:
```bash
npm run demo
```
